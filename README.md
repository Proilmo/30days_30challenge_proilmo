# 30 Days. 30 Challenges. 🔥

For the next 30 days, this repo tracks one cybersecurity project a day, built alongside the community.

We start from the basics and go one step further each day — nothing unnecessary, and each challenge builds on the skills learned and created in the previous one.

This isn't just about writing code and shipping projects. It's about learning and practicing together: trying things, getting stuck, helping each other out, and sharing what we've built.

Join the community on Discord: https://lnkd.in/e2_AEb3N
